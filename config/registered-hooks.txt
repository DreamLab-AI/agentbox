# registered-hooks.txt — the governed hook registry for Claude Code settings.
#
# `agentbox-manifest hooks-reconcile` (called from config/entrypoint-unified.sh
# after every hook registration block) reconciles the `hooks` block of
# ~/.claude/settings.json and $WORKSPACE/.claude/settings.json against this list
# every boot. Same model as agents/registered-agents.txt
# (ADR-2092): the settings file is a host mount that outlives every rebuild, and
# before this list nothing governed it, so `ruflo init` / the claude-flow helper
# scaffolding accreted per-turn hooks that nothing ever took away.
#
# Columns are whitespace-separated; `#` starts a comment. A row matches a hook
# entry when <marker> is a substring of its `command`.
#
#   own   <marker> <Event,Event,...> <timeout_s|->
#         agentbox's own hook. Removed from any event not listed and
#         de-duplicated; `timeout` rewritten to <timeout_s> — SECONDS, which is
#         what Claude Code reads (the registration sites used to write
#         milliseconds: `8000` was a 2.2-hour timeout). `-` leaves the value to
#         the registering block and only corrects a millisecond value.
#         Registration and gating stay in the entrypoint block that owns the
#         hook; the reconciler never ADDS an entry.
#   keep  <marker>
#         third-party, preserved byte-for-byte.
#   prune <marker>
#         removed wherever registered (vendor scaffolding, retired entries).
#
# Anything no row matches is PRESERVED and reported in the boot log, so a
# hand-added experiment keeps working and stays visible. Its timeout is only
# corrected when above 600 s (always the millisecond mistake).
#
# To add a hook: register it in its entrypoint block (or stacks.rs for
# profiles), add an `own` row here, and a row in config/hooks/README.md.
