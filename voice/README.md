# agentbox/voice — voice + AoE operator console

All web services and shared speech models join `visionclaw_network`; no private
voice network is required. Rebuild the core with `./agentbox.sh rebuild` so its
workspace volume, external project mounts and `.env` credentials are included.
The cockpit probes `/nip07/session` before opening its feed; an active login
uses the HttpOnly cookie. Signed fallbacks include a per-request nonce, and the
loopback bridge verifies the original public host and `/bridge` path forwarded
through the identity proxy. `voice health` checks the backend's dependency JSON,
including its authenticated LLM connection, rather than HTTP status alone.

The **operator cockpit**: one same-origin surface that unifies the local
**voice loop** and the **AoE session board** as co-equals — voice control of the
agent plane on one side, the live session/approvals view on the other. This is
the relocated + re-imagined home of what used to live in the untracked host
tree `voice-stack/` (Decision D0, ADR-044). It lives in agentbox because the
code it wires is agentbox's: tab0-bridge, the Agent-of-Empires plane, the NIP-98
sole-ingress proxy, and management-api governance.

```
laptop / phone / tablet browser (tailnet, self-signed TLS)
  └─ https://<host>:8444  operator console — ONE origin, ONE credential
       ├─ /              the cockpit page  (site/, "Industrial Warmth" system)
       ├─ /embed         compact voice strip  → frontend:3000  (web client)
       ├─ /api/*         Web backend          → backend:80     (STT/Pocket, /v1/realtime)
       ├─ /feed  /bridge/*   tab0-bridge      → agentbox:9096  (NIP-98 proxy → :8971, ADR-069)
       ├─ /aoe/*         AoE sessions         → agentbox:9096  (NIP-98 proxy → :9095)
       └─ /approvals/*   governance           → agentbox:9090  (management-api)
       ├─ /mgmt/*        system discovery     → agentbox:9090  (authenticated)
       ├─ /lo/*          linked objects       → agentbox:9090  (public bundle)
       └─ /docs/*        OpenAPI / Swagger    → agentbox:9090  (public shell)
  └─ https://<host>:8443  web voice debug UI (diagnostics only)

unified speech plane (on visionclaw_network)
  ├─ Pocket TTS   pocket-tts:8000  (shared, streaming, CPU-only)
  ├─ Nemotron ASR speech-to-text:8000 (shared, cache-aware streaming, GPU 0)
  └─ web backend → tab0-bridge:8971 (OpenAI-compatible; auth: BRIDGE_TOKEN)
```

## Layout

| Path | What |
|---|---|
| `console/Caddyfile` | The operator origin routing (:8444 cockpit, :8443 debug). Adds `/aoe/*`, `/approvals/*`; forwards `Authorization` to tab0-bridge. |
| `console/site/` | The cockpit page — `index.html` / `app.js` / `styles.css`. |
| `console/certs/` | Self-signed TLS pair. **Gitignored, never committed** — generated by `agentbox.sh voice up`. |
| `compose.web.yml` | Maintained web client and backend definitions; speech is provided by the shared plane. |
| `unmute-override.yml` | Runtime overrides for shared speech, LLM = tab0-bridge, `KYUTAI_LLM_API_KEY=${BRIDGE_TOKEN}`, and traefik off :80. |
| `nemotron/` | Nemotron 3.5 cache-aware streaming ASR image and compatibility service. |
| `pocket/` | Pinned CPU Pocket TTS image, service API, cancellation patch and contract tests. |
| `../docker-compose.speech.yml` | Unified Nemotron ASR + Pocket TTS plane, started with core AgentBox. |
| `../docker-compose.voice.yml` | The Caddy console sidecar service (browsercontainer pattern). |

The Kyutai Unmute fork itself is **not vendored** (26 GB, its own `.git`, an
upstream `kyutai-labs/unmute` clone). It is an external build context at
`voice-stack/unmute`, referenced via `VOICE_UNMUTE_DIR`. Follow-up (ADR-044):
pin it to a build-arg commit / published image the way
`browsercontainer/Dockerfile` pins Chrome.

## Operate

```bash
./agentbox.sh up              # start core AgentBox + shared Nemotron/Pocket speech
./agentbox.sh voice up        # gen certs if absent, build + start web voice UI + console
./agentbox.sh voice open      # open the cockpit in the local browser
./agentbox.sh voice health    # check console, backend and unified speech plane
./agentbox.sh voice logs      # follow logs
./agentbox.sh voice status    # compose ps
./agentbox.sh voice certs     # regenerate the self-signed TLS pair
./agentbox.sh voice down      # stop UI; shared speech remains available
```

`voice up` first ensures the shared `agentbox-speech` project is healthy, then
composes `voice/compose.web.yml` + `voice/unmute-override.yml` +
`docker-compose.voice.yml` into the `agentbox-voice` project. The external
checkout supplies web client/backend build contexts only; its legacy STT, TTS,
and LLM containers are not part of the deployed graph. If that checkout is absent, the console
still starts, while `/embed` and `/api` remain unavailable.

### Environment

| Var | Default | Purpose |
|---|---|---|
| `VOICE_UNMUTE_DIR` | `../voice-stack/unmute` (rel. to the agentbox checkout) | Source checkout used to build the web client and backend. |
| `VOICE_HOST_ROOT` | `/mnt/mldata/githubs/AR-AI-Knowledge-Graph` | **Host** path mapping to the container's `~/workspace/project`. Every compose bind SOURCE resolves on the host daemon; override if your checkout is elsewhere. |
| `BRIDGE_TOKEN` | *(unset)* | Bearer the web backend presents to tab0-bridge (`KYUTAI_LLM_API_KEY`). Must match the bridge's token once it enforces global auth (Part A finding 1). |

> **Host-path note.** The docker CLI here drives the **host** daemon, so every
> bind mount SOURCE resolves on the host filesystem — never the container's.
> That is why bind sources are absolute-via-`VOICE_HOST_ROOT`, not relative.

## Auth model

The console authenticates to `/aoe/*` and `/approvals/*` with a **NIP-98**
(kind-27235) header signed via `window.nostr` (NIP-07), falling back to a
**break-glass bearer** field (stored in `sessionStorage`). Caddy forwards
`Authorization` to all three upstreams. Server-side:

- `/aoe/*` → the NIP-98 proxy (:9096) verifies the header → session pubkey.
- `/approvals/*` → management-api; **Approve/Deny is operator-gated** (Part A
  finding 2) — present an operator/allowlisted key.
- `/feed` + `/bridge/*` → tab0-bridge global auth (Part A finding 1).

Mic capture needs a secure context, hence the self-signed TLS origin — accept
the cert once per device.

## Same-origin route contract (for the console client)

All served under `https://<host>:8444`, same origin:

| Route | Upstream | Notes |
|---|---|---|
| `/embed`, `/_next/*`, voice worker assets | `frontend:3000` | Web mic strip |
| `/api/*` | `backend:80` | Web conversation backend, `/v1/realtime` WS |
| `/feed` | `agentbox:9096` | tab0-bridge turn feed (WS), **via the NIP-98 proxy** — ADR-069 credential exchange injects `BRIDGE_TOKEN` server-side (`console/Caddyfile:97-101`) |
| `/bridge/*` | `agentbox:9096` | tab0-bridge REST — tabs, `/tab0/send`, `nostr/*` — **via the NIP-98 proxy**, same server-side credential exchange (`console/Caddyfile:102-105`) |
| `/aoe/*` | `agentbox:9096` | AoE sessions API + session live-ws (WS), via NIP-98 proxy |
| `/approvals/*` | `agentbox:9090` | `GET /v1/approvals`, `POST /v1/approvals/:id/decide` |
| `/mgmt/*` | `agentbox:9090` | Authenticated system discovery, including `GET /v1/system`. |
| `/lo/*` | `agentbox:9090` | Linked-object viewer bundle and its restricted resolver proxy. |
| `/docs/*` | `agentbox:9090` | Swagger shell; operations use bearer or NIP-98 via Authorize. |

The **tab-0 coordinator session** the voice `/send` path targets is slug
`tab0` (`[interaction_plane.coordinator]`, terminal view — required for the
send-keys path).
