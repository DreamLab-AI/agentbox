# registered-skills.txt — the curated set of skills exposed to the Claude Code
# harness (i.e. symlinked into ~/.claude/skills/ so they appear in the native Skill
# list). Every other skill under /opt/agentbox/skills remains reference-only and is
# reached via the progressive-discovery layer (SKILL-DIRECTORY.md + skill-router +
# lazy-fetch).
#
# This file is the SINGLE SOURCE OF TRUTH for harness skill registration. The boot
# reconciler (scripts/reconcile-skills.sh, called from config/entrypoint-unified.sh)
# symlinks each name below from /opt/agentbox/skills/<name> into ~/.claude/skills/<name>
# every boot — idempotent, fail-open. To register a new skill: add its directory name
# here (it must have /opt/agentbox/skills/<name>/SKILL.md). Blank lines and #comments
# are ignored.
#
# WHY a curated subset and not every baked skill: the native Skill list is always in
# context, so keeping it small preserves the token budget; heavier/rarer skills are
# discovered on demand through the router.
#
# This list is NOT the router's candidate set. With [skills.routing].scope = "all"
# (ADR-2192) the routing hook offers every baked skill to the judge and injects the
# SKILL.md path of a pick that is not listed here, so a skill does not need to be
# registered to be found. Register one only when it is used often enough to be worth
# its description in every turn's context.
