# Production manifest and delivery

## Project layout

Keep the project next to the nominated repository or in the user's output folder:

```text
explainer-project/
  research.md
  plan.json
  assets/             screenshots, diagram/animation exports, model clips
  audio/              measured per-scene speech
  workflows/          executed ComfyUI API graphs and history receipts
  review.md
  delivery-v1/        generated by the compositor
```

Each narration claim should have a source excerpt or line range in `research.md`.
The manifest's evidence list points to the underlying files; the renderer hashes
those files but does not assert the narration follows from them.

## Manifest v1

Paths are relative to `plan.json`, except `evidence`, which is relative to
`repo_root`. Absolute asset paths are supported. Width/height must be even,
160–3840 and 90–3840 respectively; fps is 1–60. Duration is seconds, greater than
zero and at most 300 per scene. IDs are unique `[a-z0-9_-]+` strings. Plan JSON
must contain these fields. Add an optional `font_file` path to a licensed TTF/OTF
font for consistent brand typography; otherwise FFmpeg uses its installed default:

```json
{
  "schema_version": 1,
  "title": "A verified introduction to the project",
  "audience": "Engineers joining the team",
  "repo_root": "../my-repository",
  "width": 1920,
  "height": 1080,
  "fps": 24,
  "scenes": [
    {
      "id": "architecture",
      "kind": "diagram",
      "title": "From request to response",
      "nodes": ["Client", "API", "Storage"],
      "duration": 7.2,
      "narration": "The client sends a request. The API checks it before reading storage.",
      "audio": "audio/architecture.wav",
      "evidence": ["src/api.py"]
    },
    {
      "id": "demonstration",
      "kind": "image",
      "asset": "assets/verified-screen.png",
      "motion": false,
      "title": "One useful interaction",
      "caption": "A short, exact interface label",
      "duration": 6.5,
      "narration": "Replace this example with the specific behaviour verified in the repository.",
      "audio": "audio/demonstration.wav",
      "evidence": ["src/api.py"]
    },
    {
      "id": "hero",
      "kind": "video",
      "role": "hero",
      "asset": "assets/local-hero.mp4",
      "title": "An illustrative visual metaphor",
      "duration": 5.5,
      "narration": "Replace this line with the audience's concrete takeaway.",
      "audio": "audio/hero.wav",
      "generation": {
        "model": "exact model filename and revision",
        "workflow": "workflows/hero-api.json",
        "prompt_id": "actual completed ComfyUI prompt ID",
        "receipt": "workflows/hero-comfy-receipt.json",
        "seed": 12345
      },
      "evidence": ["README.md"]
    }
  ]
}
```

This is a schema illustration, not a runnable fixture: create the assets, source
files and speech before validation. The fourth kind, `title`, renders a clean
text card without an asset; use sparingly. Image scenes preserve aspect ratio
with letterboxing; optional gentle centred zoom defaults on. Turn it off for
screenshots whose edge labels matter. Videos play once and hold their last frame
when shorter than the narration; choose scene lengths/edits intentionally so this
does not produce a visible accidental freeze. The compositor replaces clip audio
with narration. Diagram nodes are a top-to-bottom sequence, revealed in order;
for branching graphs render an accurate external diagram/animation asset.

Every scene needs `title`, `narration`, `duration`, `evidence`. Keep titles short,
at most two lines in the target frame. Title and caption wrapping use the
frame width, actual configured font size and a safe margin, so portrait layouts
need shorter text. The helper conservatively budgets one em per character;
review custom font glyph widths in the rendered export. `caption` is optional exact on-screen copy;
it is separate from accessible narration subtitles. Video/diagram content stays
inside the safe region below the title band and above caption overlays. Generated
hero scenes additionally need `role: hero` and `generation`; the workflow path
must exist. Every present `generation` object, including non-hero scenes,
requires the same model/workflow/prompt ID strings. Optional `generation.receipt`
points to the durable ComfyUI execution receipt and must exist when supplied.
The output receipt records each generated scene ID, its asset hash, workflow
file hash and optional execution receipt hash; workflow and receipt files also
appear in the asset hash map. These hashes establish artifact identity, while
checking the durable receipt against server history establishes runtime provenance.
Preserve model download and license provenance alongside that graph.
The renderer checks metadata presence; the ComfyUI execution receipt proves the
actual model ran. Do not invent a prompt ID or relabel a synthetic fixture as AI
video.

## Narration and captions

Use the available local speech service's documented endpoint and preserve its
request parameters without credentials. If only an external provider is
available, follow the user's data and cost instructions before using it. User
recordings are equally valid. Test voice quality on the first two sentences
before generating the whole script. Choose final durations from measured files:

```bash
ffprobe -v error -show_entries format=duration -of default=nw=1:nk=1 \
  /absolute/project/audio/architecture.wav
```

A scene may pad the end of narration with silence; it may not cut narration off.
The helper checks that audio is present and fits the timeline. It cannot prove
that a file contains the intended speech: listen and compare it to the transcript.
Narration is normalised towards -16 LUFS / -1.5 dB true peak per scene. Background
music is optional and should be mixed separately with speech ducking; omit it if
it reduces clarity.

The supplied SRT is divided into two lines of at most 42 characters and spaced across each
scene duration, with a minimum one second per cue and at most 25 characters per
second. Retiming is required when narration exceeds this reading budget. This is coarse scene timing, **not speech alignment**. For accurate
speech captions, replace the SRT with the local aligner's timestamped result and
remux it. A narration edit invalidates previous caption alignment and timing.
Selectable MP4 captions are enabled through the player's caption control; for
social exports that need permanent captions, use the **ffmpeg-processing** skill
and the rendered SRT, and review safe areas on the target aspect ratio.

## Repeatable local narration with Kokoro

On Nix-based runtimes, an installed wheel may fail to load `libstdc++.so.6` even
when its Python package is present. Run in a development shell with the GCC
runtime available, or include the directory reported by
`dirname "$(g++ -print-file-name=libstdc++.so.6)"` in `LD_LIBRARY_PATH` for the
narration process. Preserve the underlying import error when diagnosing this.
Use a writable project cache via `UV_CACHE_DIR` if the home cache is a small tmpfs.

The optional helper uses [Kokoro-ONNX](https://github.com/thewh1teagle/kokoro-onnx)
on CPU, leaving the GPU available for video. Its isolated environment is created
inside the production project, not installed into Agentbox's managed Python:

```bash
uv venv /absolute/project/tts-venv
uv pip install --python /absolute/project/tts-venv/bin/python \
  'kokoro-onnx==0.6.1' soundfile
```

Download `kokoro-v1.0.onnx` and `voices-v1.0.bin` from the official
[model-files-v1.0 release](https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0)
to a reusable model folder. Record the release and downloaded hashes. Check the
current upstream documentation when intentionally changing the model version;
model and voices must be a compatible pair. The helper receives explicit paths
and never downloads or silently upgrades a model.

```bash
/absolute/project/tts-venv/bin/python scripts/narrate.py \
  /absolute/project/plan.json --output /absolute/project/narration-v1 \
  --model /absolute/models/kokoro-v1.0.onnx \
  --voices /absolute/models/voices-v1.0.bin \
  --voice af_sarah --lang en-us --speed 1.0 --breathing 0.3
python3 scripts/video_project.py validate /absolute/project/narration-v1/plan.json
python3 scripts/video_project.py compose /absolute/project/narration-v1/plan.json \
  --output /absolute/project/delivery-v1
```

The output directory must be new. The source plan is preserved. Each scene gets a
WAV, a measured speech duration and a frame-aligned scene duration that covers
speech plus breathing time and the caption reading budget. The generated
`plan.json` resolves original asset paths, and `narration-receipt.json` preserves
model/voice hashes, package version, voice settings and audio hashes. Visual
assets can still be in progress while speech is generated; run full video plan
validation after those assets exist. Listen before full composition. A numerical
non-silence check catches empty model output, not incorrect speech.

## Quality evidence

`validate` checks structure, file existence, evidence confinement, audio streams
and duration; `compose` invokes it before rendering. The final receipt records
input and output hashes and ffprobe stream details. The included integration
test renders all four visual kinds with synthetic test audio; that establishes
composition mechanics, **not** model generation, speech quality or an end-to-end
codebase explanation.

Run tests after changing the helper:

```bash
python3 -m unittest discover -s tests -v
```

Before marking a production video complete, inspect frames from every scene at
full output size, listen through the whole film, and check:

- The nominated audience understands the problem, mechanism and next action.
- Every assertion matches the inspected revision and running behaviour.
- Screenshots/code text are readable and show a real app or command.
- Diagram edges and ordering reflect actual implementation.
- Generated shots have no visual corruption or fabricated product features.
- Narration pronunciation, pauses and scene cuts are natural.
- Captions contain the spoken wording and meet the destination's timing needs.
- The complete export has sound, correct orientation/runtime and no missing shots.

Keep the render receipt separate from editorial `review.md`. Neither a validator
nor a file called `review.md` substitutes for the actual inspection.
