# Moving from build-with-quality

VisionCraft is the portable successor method and executable contract. Agentbox
cuts over all active callers once the new implementation passes its gates, then
removes the old entrypoint; no compatibility period or redirect remains active.
[The path map](../assets/legacy-paths.json) accounts for all
28 original files and distinguishes preserved resources, rewritten guidance,
host-owned adapters and explicit retirement.

Uppercase activation/protocol/example files now live under `assets/` or
`references/`. Rust resource paths remain available beneath the canonical skill.
Agentbox's direct-path migrations belong to its adapter and installation
tests. [The integration reference](ecosystem-agentbox.md) identifies the related
registries, routers, stack projection and runtime checks.

Agentbox removed the old TypeScript/npm API in September 2026;
VisionCraft does not revive its classes, factories or imports. The old
`config/skill.yaml` described policy but had no discovered current loader. It is
retired rather than carried forward as inert runtime configuration. Use the
actual released CLI/library schema and the host's declared policy.

Historic role records, automatic learning, consensus labels and performance
targets do not describe implemented VisionCraft services. Useful engineering
responsibilities remain in [roles](roles.md); host features remain integrations.
Recorded prior evidence keeps its original version and conclusions.
