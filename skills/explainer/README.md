# explainer

Family hub for three codebase-explainer deliveries — a docs bundle, an
instructional microsite, or a video — sharing one grounding contract. Read
`SKILL.md`. Registered with the Claude Code `Skill` tool and the Codex skill index
(`registered-skills.txt`, `codex-registered-skills.txt`); on a plain filesystem
install, reading `SKILL.md` is the invocation.

Pilots against one private repository, September 2026: a docs bundle, then a
microsite that its owner rejected for narrating its own making, then the rewrite
that replaced it (`references/microsite/reader-voice.md`, the addendum in
`SKILL.md`). Evals live in `evals/`; the mechanical gates in `scripts/`.
